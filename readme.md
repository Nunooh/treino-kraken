# 🐙 Treino do Kraken — Simulador Comunitário

Mini-jogo gratuito feito para ajudar a comunidade a praticar a mecânica de puxar o Kraken no navegador (PC e telemóvel), disponível em **PT-BR, EN, ES e FR**.

👉 **[Clique aqui para abrir o simulador](https://nunooh.github.io/treino-kraken/)** 

---

## 🔒 Segurança e Privacidade

Como a segurança das contas é prioridade na comunidade, este projeto foi construído para ser **100% transparente e verificável**:

- **Nunca pede login nem dados pessoais:** Este site não solicita senha, e-mail, nickname, cookies ou qualquer dado da sua conta.
- **Código 100% aberto e legível:** Todo o jogo está contido num único ficheiro (`index.html`), sem código escondido, compactado ou ofuscado. Qualquer pessoa pode abri-lo aqui no GitHub e ler o código linha por linha.
- **Sem servidor próprio e sem rastreadores:** É uma página estática hospedada gratuitamente no GitHub Pages que corre apenas no seu próprio navegador. Não possui anúncios, Google Analytics, cookies de rastreamento nem scripts de terceiros.
- **Sem downloads:** Tudo funciona diretamente no browser, sem precisar de instalar extensões ou programas.

### O que este site utiliza exatamente?
Para total transparência, as únicas interações técnicas do ficheiro `index.html` são:
1. **Google Fonts:** Carregamento das fontes em estilo pixel art (`Silkscreen` e `VT323`).
2. **`localStorage` do navegador:** Guarda apenas uma palavra (`pt`, `en`, `es` ou `fr`) localmente no seu aparelho para lembrar o idioma escolhido. Nenhum dado sai do seu dispositivo.

## 🔍 Como conferir por conta própria

Se quiser verificar a segurança do projeto antes de jogar:
1. Clique no ficheiro **`index.html`** neste repositório.
2. Pressione `Ctrl + F` e procure por `fetch`, `XMLHttpRequest`, `form` ou `document.cookie` — verá que **não existe nenhum envio de dados**.
3. Ao abrir o site no navegador, pode abrir as Ferramentas de Programador (`F12` → aba **Network / Rede**) para confirmar que não há qualquer comunicação com servidores desconhecidos.

---

## 🎮 Como usar o simulador

- **Segure `ESPAÇO`**, clique no mostrador ou no botão circular para mover o ponteiro para a direita.
- **Solte** para o ponteiro voltar para a esquerda.
- Mantenha o ponteiro dentro da área do Kraken (que fica **totalmente amarela** quando acerta) até encher a barra.
- **Modo Tutorial vs. Comunidade:** Desmarque a opção *"Destacar Meu Ponteiro (Tutorial)"* para treinar no meio de vários ponteiros simulando a sala cheia.
